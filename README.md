# NFZ public-payer settlement decomposition — current R pipeline (20 Oct 2026)

Code accompanying the *Value in Health* methodological manuscript, **A Model-Based Shapley Framework for Decomposing Temporal Changes in Public-Payer Settlement Value: Validation Against an Aggregate LMDI-Style Benchmark**.

## What is the primary analysis?

The manuscript's **primary specification remains the original GAM chain**: negative-binomial patient and service counts, Gamma value model; patient GAM includes the `s(code,bs="re")` random intercept, **not** MRF, expanded `code × age/sex` terms or regional slopes. Four Shapley factors: population N, treatment reach PI, service intensity LAMBDA, and settlement-point valuation KAPPA. Published empirical interpretation applies to settlement points, not costs.

The alternative patients-model specifications are **exploratory sensitivity analyses**, not changes to the primary estimation chain. They were tested on licensed NFZ data but no models or administrative data are bundled with the code.

## Environment / dependencies

R >= 4.5 is recommended. Essential packages: `mgcv`, `data.table`, `dplyr`, `tidyr`, `readr`, `stringr`, `purrr`, `tibble`, `ggplot2`, `scales`, `MASS`. Diagnostic tools additionally use `spdep`; see script source for optional packages. Tested locally by the author, but this reconstructed source archive **has not been end-to-end executed without the restricted NFZ input**.

## Configuration and input

From the project root:

```r
file.copy('config.example.R', 'config.R', overwrite=FALSE)
```

Edit `config.R` and place the licensed input extract at `config$data$path` (default `data/dane_2018_2024.csv`). Keep `model$value_family='gamma'`, `model$use_spatial_smooth=FALSE`, and `model$k_year=5` to preserve the manuscript's **primary** specifications. Do not publish `config.R`, source NFZ data, row-level residuals, fitted RDS objects, or unapproved derived tables.

## Main analysis

```sh
Rscript scripts/run_pipeline.R --preflight
Rscript scripts/run_pipeline.R --quick
Rscript scripts/run_pipeline.R --full --figures
Rscript scripts/export_submission.R
```

`--quick` reduces simulations/bootstrap to 20 replicates **and must not be used for publication**. `--full` recomputes expensive analysis by default. Use `--reuse-cache` only after validating cache provenance. The exporter is for the original analysis tables/figures; a journal-compliant anonymous manuscript/cover letter is a separate editorial package.

### Spatial diagnostics, specification sensitivity, audit

These are additional scripts incorporated **after** the previous v4 pipeline export. None is part of the primary model by default:

```sh
Rscript scripts/run_postpublication_diagnostics.R --help
Rscript scripts/run_postpublication_diagnostics.R --moran-re
Rscript scripts/run_postpublication_diagnostics.R --moran-block
Rscript scripts/run_postpublication_diagnostics.R --sensitivity
Rscript scripts/run_postpublication_diagnostics.R --audit
```

- `run_moran_re_only.R`: Pearson-residual Moran by year × sex × age cells, 8-NN; avoids averaging all years and demographics per administrative unit. Reported median for primary patient RE model 0.259 (kNN-8).
- `run_moran_cell_block_pilot.R`: block Moran on original cell residuals, kNN 4/8/12; within-block restricted permutations (saved pilot RE, MRF and RE+MRF models **required**).
- `run_pilot_patients_*` and `run_pilot_patients_missing_terms.R`: expensive optional patient-model candidates, including code-age effects, regional slopes, code-sex, pandemic, population terms, year-spline basis k=5/6/7; these are **not** invoked in the canonical pipeline.
- `run_fast_shapley_model_sensitivity.R`: all 16 independent N, PI, LAMBDA, KAPPA switches, using locally saved existing model fits; no refitting. It requires `output/rds/{model_fit,aggregated_data}.rds` plus exploratory patient-model caches generated by optional pilot scripts. Fast sensitivity is **not executable from the public repository alone** without authorized data/fits.
- `run_audit_fast_shapley_RE.R`: independently compares all 16 RE scenarios against the original `R/03_predict_helpers.R`; on the authors' local run all 16 matched with maximum absolute difference zero.

All diagnostics should be interpreted as descriptive effect sizes. The cell/block Moran statistics use a symmetric k-nearest-neighbour proxy, **not** administrative shared-boundary adjacency. The more complex models improve fit and reduce residual Moran but were not selected as the manuscript's primary models. This is a robustness demonstration, not a search for a spatial prediction optimum.

## Safe sharing and reproducibility limits

The input consists of restricted NFZ-provided aggregated administrative cells. Although already aggregated, the granular extract **cannot be redistributed**. Only sufficiently aggregated non-identifying verification summaries can be shared subject to data-provider rules. Manuscript tables and numerical summaries are not bundled with this repository by default. Synthetic simulation routines are included; they do not grant access to restricted NFZ data. A fully independent rerun of the empirical analysis needs lawful data access.

## What changed since the old GitHub pipeline?

1. Canonical `scripts/run_pipeline.R` and curated VIH figure exporter v4 preserved.
2. Corrected offset/logger pilot script for RE/MRF comparison.
3. Added cell-level/block-level Moran diagnostics with no cross-stratum residual averaging.
4. Added age, sex, regional slope, pandemic, population and time-basis sensitivity pilots.
5. Added *corrected* fast Shapley model-sensitivity calculation (endpoint cell-grid fix).
6. Added original-helper audit of all 16 RE counterfactual states, observed max discrepancy **0 settlement points**.
7. Sensitive caches and fitted objects are excluded from the repository.

No claim is made that the main Gamma/RE chain has been re-estimated after these sensitivity tests. Historical scripts `run_12`–`run_14` remain audit-oriented and can refit alternate specifications; they should not be confused with the primary manuscript output.
